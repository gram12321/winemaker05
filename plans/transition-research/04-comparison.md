# Topic 04 — Cross-game comparison

Neither inspected sibling provides a wine-sensory projection analogue. Office Tycoon’s `developmentEngine.ts` converts accumulated work into bounded architecture and feature quality, averages each feature’s quality and extent, then weights that average with architecture quality (`C:\GitHub\officetycoon\src\engine\product\developmentEngine.ts:100-111,128-162,165-234`). The resulting scalar describes software development progress and bug pressure, not observable material traits. Its tests check weighted composition, isolated bug penalties, and invalid bounds (`C:\GitHub\officetycoon\tests\developmentEngine.test.ts:100-119,173-208,258-277`). Useful patterns are deterministic recalculation, explicit validation, and keeping one contributor’s effect isolated.

Industri Clicker’s `qualityMath.ts` computes quantity-weighted input quality, derives input and other ceilings, and returns a breakdown whose output quality is constrained by the minimum applicable ceiling (`C:\GitHub\industriClicker\game\quality\qualityMath.ts:76-107`). Its tests verify weighted inputs, ceiling selection, bonuses, and curve behavior (`C:\GitHub\industriClicker\tests\quality\qualityMath.test.ts:36-87`). That is an economic scalar for recipe output; neither its Q scale nor its minimum-ceiling rule models current sensory expression.

For 05, keep the current `deriveStructure(lot)` boundary pure and deterministic, returning the six normalized `StructureProfile` axes without reading scores or targets (`plans/transition-contracts.md:20-22`; `src/game/evaluation/types.ts:1-2`). Derive from `PhysicalLot.physical`; use immutable anchors only as potential or response capacity, avoiding a second additive copy of current material (`src/game/wine/types.ts:3-10,24-41,63-76`). Several current axes lack direct physical fields: sweetness, body, and spice need explicit mappings, and varietal spice may require grape identity or an added inherited input. The exact taxonomy and equations remain open in `docs/WorkingDocs/design.md:121-124`; do not present proposed mappings as wine chemistry.

Recommended focused tests: repeated calls return identical finite 0–1 values for all axes and leave the lot unchanged; controlled sugar depletion, acidity/aroma shifts, phenolic extraction, alcohol/lees development, and oak/maturation changes affect their intended projections; changing targets or scores cannot affect projection; current projection can evolve while a stored bottling assessment remains fixed. These are recommendations, not checks run in this research.
