# Receiving Code Review

Read all relevant feedback, understand the affected behavior, and verify each actionable claim against current code and requirements. Correct confirmed defects within scope; explain specific evidence when a suggestion is incorrect or conflicts with the user's direction.

If an item is ambiguous, ask a focused question where necessary while continuing independent, understood work. Use proportional checks for each meaningful fix and report results or remaining gaps. Do not send external review replies or resolve remote threads unless the user has authorized that action.
