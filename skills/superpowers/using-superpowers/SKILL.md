# Using Superpowers

Start with the [Winemaker router](../../winemaker-game/SKILL.md) and select the smallest relevant specialist workflow. Read the selected skill before using it. Do not run every workflow or expand the user's request merely because a skill exists.

Use planning, debugging, review, verification, isolation, or delegation when their actual triggers apply. Follow the user's choices and the execution environment's permissions; a skill does not grant authorization for commits, external actions, or subagents.
