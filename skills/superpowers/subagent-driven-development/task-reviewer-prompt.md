# Task Review Brief

Use for authorized, read-only review of a delegated slice. Provide the task requirements, relevant global constraints, changed paths or complete diff, and checks actually run.

Inspect the changed files and enough surrounding code to verify both requirement coverage and quality. Report concrete findings with file and line, affected scenario, evidence, impact, and a practical correction. Separate unresolved verification gaps from defects. Do not mutate code, Git state, or external review threads.
