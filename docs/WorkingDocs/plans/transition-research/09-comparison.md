# Topic 09 comparison: causal wine risks

Approved 05 direction requires time-dependent wine development and keeps physical faults distinct from structural balance ([`docs/WorkingDocs/design.md`](../../docs/WorkingDocs/design.md), decisions 13, 16, 28, 39). Migration row 142 says to rebuild risk behavior around wine causes, using explicit inputs and traceable outcomes; Office Tycoon’s software bugs are a comparison, not a wine model ([`docs/WorkingDocs/Winemaker04_to_05_System_Migration_Research.md`](../../docs/WorkingDocs/Winemaker04_to_05_System_Migration_Research.md)).

Office’s `C:/GitHub/officetycoon/src/engine/product/bugEngine.ts` calculates per-target chance from work, complexity, design quality and source, accepts an injected random function, and records source-linked open/fixed bugs. `C:/GitHub/officetycoon/src/engine/product/developmentEngine.ts` supplies architecture and feature targets. `C:/GitHub/officetycoon/tests/developmentEngine.test.ts` proves forced clean/bugged outcomes and source-specific quality effects with seeded functions. Reuse explicit causal attribution and controllable scenarios; do not copy software bug records, random occurrence, or detached quality penalties as wine faults.

05 already names risk-owned `PhysicalState` fields `oxygenExposure`, `oxidation`, `rot`, and `greenCharacter`, and `WineEnvironment` fields `oxygenIngress` and `contaminationRisk` ([`src/game/wine/types.ts`](../../src/game/wine/types.ts)). `plans/transition-contracts.md` assigns once-per-day advancement of those cumulative fields to `wine/Risks.ts`, then derives `oxidation`, `spoilage`, `green-character`, and conditional `stuck-fermentation` diagnoses. `WineFault` carries code, severity and explanation; assessment keeps faults separate from structure ([`src/game/evaluation/types.ts`](../../src/game/evaluation/types.ts)). The contract exists, but `src/game/wine/Risks.ts` is not implemented yet. Existing pressing already makes intensity affect oxygen exposure (`tests/game/wine-operations.test.ts`).

Proposed scenarios: identical lot, environment and days yield identical risk state and diagnoses; zero oxygen ingress adds no oxygen-driven oxidation, while greater ingress over equal time cannot reduce exposure/oxidation; contamination risk changes rot only under its declared conditions; active fermentation with sugar and insufficient yeast diagnoses stuck fermentation, while dry or inactive lots do not; increasing a physical fault changes diagnosis/severity without changing structural fit. Forecasting and daily advancement must use the same deterministic rule path.
