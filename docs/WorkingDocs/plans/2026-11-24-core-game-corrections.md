# Core game corrections — working plan

**Goal:** Correct the implemented Winemaker05 core loop as it is tested, with a working interface and reliable presentation. The human may add or change tasks here while work is underway; read the latest document before each assignment and preserve those edits.

**Scope:** Existing vineyard-to-sale core gameplay and its interface. The broader supporting systems excluded from the [transition plan](2026-11-21-core-game-transition.md) remain outside scope unless explicitly added. Current source and approved [design](../design.md) govern implementation; Winemaker04 and sibling games are references, not 05 facts.

**Workflow:** For each applicable task, record research, implementation, independent review, and focused verification. The orchestrator integrates results; coding is delegated by default. Assign one owner per writable file when work overlaps. Do not commit or publish. Mark a task complete only after its acceptance checks pass, and record limitations honestly.
